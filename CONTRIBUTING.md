# Panduan Kontribusi

Terima kasih sudah mau berkontribusi ke repo ini!

## Cara berkontribusi

1. Fork repo ini
2. Buat branch baru, contoh: `git checkout -b tambahan/namamu`
3. Tambah catatan Git yang belum ada di repo ini
4. Commit dan buka Pull Request (PR) dengan deskripsi yang jelas

## Aturan kecil

- Pastikan perintah yang kamu tulis sudah kamu coba sendiri dulu
- Judul commit singkat dan jelas
- Jangan ubah README utama tanpa diskusi dulu
